One War, Many Narratives

A cross-layer sentiment analysis of media framing, editorial opinions, and public discourse on the Iran-Israel conflict.

📋 Project Overview

This project is undertaken to analyze how global media channels portray the same war with different narrative lenses. This project consists of a cross layer synthesis of how different media outlets frames the current war with different themes. This analysis is added with an analysis of editorial opinions and public opinions (via social media comments) to identify the gaps in media framing and public sentiment. to identify the key themes and sentiments across different media channels and public discourse.

The project utilises LDA topic modelling and sentiment analysis NLP techniques in python. Kindly note that the results are purely based out of results arrived at from the text mining through the program. This may or may not be true in the real sense. It is just an attempt to understand whether perspective differences persist among different global media outlets in narrating the same war.

This project was undertaken as part of my text analytics course during my MBA program

🔍 Key Analytical Areas

Topic Modelling

Examining whether different media outlets from different regions frame the same war through different lenses with contrasting perspectives.

Text Classification

Classifying news statements to particular media channels based on repeated usage of specific terms and phrases and dominant themes covered.

Sentiment Analysis

Examining how sentiment in language shifted over time and across key events (for all 3 layers: news articles, editorial opinions, and YouTube comments).
