Spotify Tracks Popularity Classification

Machine learning project using Python and scikit-learn to classify Spotify tracks into High, Medium, or Low commercial popularity.

📋 Project Overview

The music industry spends millions signing artists, producing albums, and funding campaigns, often without a strong data-driven basis for deciding which songs deserve that investment.

This project asks a direct question relevant to record labels: can we predict whether a song will become a chart-topper, a mainstream track, or remain largely undiscovered before release?

Using Spotify audio measurements for 114,000 songs across 114 genres, I built a Random Forest classifier to place each track into one of three popularity categories: High, Medium, or Low.

The model achieved a 74% accuracy and a weighted F1-score of 72.7%, making it a practical screening tool for guiding marketing decisions.

This project was undertaken as part of my machine learning course during my MBA program.

🎵 Model Performance & Key Findings

Model Accuracy

74% accuracy achieved using a Random Forest classifier across High, Medium, and Low popularity tiers.

F1-Score

Weighted F1-score: 72.7%, indicating balanced performance across all three classes.

Feature Importance

Audio features such as energy, danceability, and valence emerged as strong predictors of popularity.

Business Impact

The model can help record labels identify high-potential tracks before release and allocate marketing spend more strategically.
